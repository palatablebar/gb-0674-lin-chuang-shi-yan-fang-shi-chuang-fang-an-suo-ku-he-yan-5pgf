# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。

## 排期锚点裁决（单一锚点）

窗口、偏离与锁库共用同一排期锚点，不允许同一受试者出现两套阻断口径。锚点按受试者逐人裁决，落在 `anchors` 表：

- `ENROLLMENT`（入组锚点）：首访在入组基准窗内，或首访缺失/重复不具备重锚条件时，锚点日期=入组日期，`shift_days=0`，全部访视按入组基准排窗。
- `ACTUAL_FIRST`（实际首访锚点）：首访唯一且落在入组基准窗外（提前或推迟）时，锚点日期=该首访的实际日历日，`shift_days=实际首访日−入组日`。首访之后的各次访视从实际首访重新起算（访视日=采样日−锚点日），窗的偏移区间仍取所选方案的原定义，避免把患者压进过密日程。

首访（V1）本身始终按入组基准评判并留痕：它的窗外偏离是触发重锚的原因，重锚不得改写或消除该偏离。缺首次访视记 MISSING_PRIMARY、重复首次记 DUPLICATE_PRIMARY，二者均不重锚，相关受试者回退入组锚点。

每条窗口结果同时带两套日历，但只有锚点口径参与偏离与锁库：`day/start_day/end_day/code` 为生效的锚点口径；`baseline_day/baseline_start_day/baseline_end_day/baseline_code` 为顺延前的入组基准口径，仅用于追溯，不产生第二条阻断结论。`anchor_source/anchor_date/shift_days` 标明该行所用锚点来源、日期与顺延天数。

PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
锁库须所有规定访视完成，无偏离、复检问题和隔离行。重算失败时保留旧批（含其可锁库结论），接口返回 RERUN_FAILED，不覆盖也不新增批次；同输入同规则版本重跑批号不变，窗口、锚点与偏离逐行一致，不新增排期或偏离。冻结包包含每条选定结果、原始行号、方案版本、访视窗与排期锚点证据。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
